Cosmetic-Generator (Nugget Client). Alle Teile Eigenbau, nichts kopiert.
- gen.js: node gen.js <Ausgabeordner> [modellname ...]  -> .bbmodel + _0.png (Kopf, Gesicht, Jetpack, Schwanz, Haustiere)
- feather.js: node feather.js out.png <phoenix|engel|eis|daemon>  -> Federn-Textur der Flügel (Modell nugget_fluegel*.bbmodel)
- dragon.js / wing2.js: Textur Mini-Drache / alte Fledermausflügel
Ergebnis nach src/main/resources/assets/nugget_client/cosmetics kopieren. Animationen sind Ausschläge (additiv zur Grundstellung).
